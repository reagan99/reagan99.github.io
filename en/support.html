01 / GET STARTED

Getting started

Can I edit code without a server?

Select New Local Project on the home screen to create, edit, and save files on your device. Use Open Folder in Files to choose an existing folder. Folders opened from Files are edited in place, not as copies, so back up important files first.

How do I connect to an SSH server?

Enter the host, port, username, and authentication method in a server profile, then connect. Before approving the host key shown on your first connection, verify its fingerprint separately with your server administrator. If the host key changes, check the reason before proceeding.

02 / CONNECTION

SSH and VPN connections

The connection gets stuck or fails.

Check the server address and SSH port, and make sure the server is running. For a private company network, connect the VPN on this iPhone or iPad. A VPN connection on your Mac is separate from the VPN connection on your physical device.

The app's network diagnostics can check the route and TCP connection to your selected server. Ask your administrator about per-app VPN or access policies. Also check the app's local network and cellular permissions in device settings.

Can a connection restart after I return from the Home Screen?

The app does not close a healthy SSH connection simply because you switch screens. However, iOS app suspension, VPN state, or server settings can cause the connection to end. The app checks the connection when you return and recovers it when needed.

For server jobs that must keep running, a session tool such as tmux lets work continue independently of the device connection. Save your edited files before closing the app.

Where are passwords and private keys stored?

SSH passwords, private keys, and passphrases managed by the app are stored in this device's Keychain and are not synchronized to other devices. Deleting a server profile also deletes the associated credentials managed by the app. Learn about device storage

03 / FILES & EDITING

Editing and file previews

I see a conflict when saving a file.

Another program may have changed the original file since you opened it. Review the changes and choose the version to keep. Unsaved edits may be lost if the app terminates, so save important changes frequently.

Are images and videos downloaded or cached?

Previews leave the original unchanged and prepare a copy in a protected device cache, then open it in an editor tab. This is different from saving a separate file to Files or Downloads. Remote files open after the full transfer finishes, so large videos may take time to prepare.

The cache is limited to 512 MiB per workspace, with older entries from closed tabs removed first. To read the original again, refresh the viewer. To clear the cache, use Close Media Tabs and Clear Cache in the workspace. Even within supported formats, playback depends on the codec and device.

Can I use special keys with the keyboard hidden?

Use the keyboard button in the terminal accessory bar to hide the onscreen keyboard. The bar stays available, so you can still use Esc, Ctrl, Alt, arrow keys, and the expanded special keypad.

04 / EXTENSIONS

Extensions

How do I use extensions?

Search for and install Open VSX packages in your workspace's Extensions section. Open an installed extension and, when prompted, review the third-party code trust notice before activating it. File viewer extensions can be used when you open a matching file in the explorer.

Extensions are third-party code created by their publishers. Local extensions can read your selected project and edit or save open documents. Server extensions run with your SSH user's permissions. Use extensions only from publishers you trust.

Why can an extension behave differently locally and over SSH?

Each extension requires its own APIs and executables. Local workspaces run commands and read-only viewers supported on the device, while SSH workspaces use the connected server's runtime. Extensions requiring Node.js or a separate executable may need a server environment.

Extensions using AI services are subject to those services' accounts and terms. Code, chats, and files may be sent to the service, so review each provider's privacy policy.

An extension or PLY viewer will not open.

Check the extension name and version, whether the workspace is local or SSH, and the error message. File viewers depend on the file format and the encoding or structure supported by the extension. Email only the minimum information needed to reproduce the issue. You do not need to send the entire original file or server credentials.

05 / CONTACT

Before you contact us

The following details can help us investigate:

  • App version and build, plus your iOS or iPadOS version
  • The screen affected and steps to reproduce the issue
  • Whether the workspace is local or SSH, and whether you use Wi-Fi, cellular data, or a VPN
  • The error text or a screenshot with sensitive information hidden
  • For extension issues, the extension name and version; for file issues, the format and approximate size

Do not send passwords, private keys, or tokens. Hide internal server addresses, usernames, file paths, code, and personal information before sharing. Copying version information in the app includes only app and OS versions; it does not automatically attach server profiles or logs.
