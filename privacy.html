1. 적용 범위

SSH Studio는 iPhone과 iPad에서 SSH 터미널, 파일 관리, 코드 편집, 미디어 미리보기와 확장 기능을 제공하는 앱입니다. 이 방침은 앱이 기기에 저장하거나 기능 수행을 위해 전달하는 정보와 사용자가 관리할 수 있는 항목을 설명합니다.

사용자가 선택한 SSH 서버, Files 제공자, 확장 저장소, 확장과 연결된 AI·로그인 서비스는 각자의 방식으로 정보를 처리할 수 있습니다. 앱의 로컬 저장과 이러한 서비스의 보관·활용은 구분됩니다.

2. 서버 연결과 파일 작업

SSH 연결 시 선택한 서버에 사용자 이름과 인증 요청을 전달합니다. 비밀번호 인증은 SSH 통신 안에서 처리하고, 공개키 인증은 기기의 개인키로 서명합니다. 개인키 원문을 인증을 위해 서버에 업로드하지 않습니다.

터미널에서 실행한 명령과 입력, SFTP로 요청한 경로와 전송한 파일 내용은 선택한 서버에서 처리합니다. SSH 터널을 사용하면 사용자가 연결한 서비스의 통신이 해당 서버를 거칠 수 있습니다.

앱은 이 자료를 자체 광고나 사용 분석을 위해 운영자 서버로 자동 업로드하지 않습니다. 서버의 접근 기록, 파일과 계정 정보의 보관·삭제는 해당 서버 운영자가 관리합니다.

로컬 프로젝트는 기기에 저장합니다. Files에서 선택한 폴더는 별도 사본이 아닌 원본을 편집하므로, 제공자의 클라우드 동기화가 켜져 있다면 변경 내용이 그 서비스로 전달될 수 있습니다.

3. 기기에 저장하는 정보

저장하는 정보와 이용 목적 및 방식
정보이용 목적과 저장 방식
서버 프로필호스트, 포트, 사용자 이름, 시작 경로, 승인한 서버 키 지문과 연결 설정을 다음 연결에 사용하기 위해 저장합니다.
SSH 자격 정보비밀번호, 개인키와 개인키 암호구는 기기의 Keychain에 저장합니다. 다른 기기로 동기화하지 않으며 기기가 잠긴 동안 Keychain에서 새로 읽을 수 없도록 설정합니다.
프로젝트와 설정로컬 프로젝트 파일, 폴더 등록 정보, 편집기·키보드 설정과 최근·즐겨찾기 폴더를 저장합니다.
스니펫과 명령 기록사용자가 만든 스니펫을 저장합니다. 명령 기록은 기본 꺼짐이며, 켠 경우 명령 입력창에서 제출한 명령을 최근 100개까지 보관합니다. 터미널의 모든 입력·출력을 자동 녹화하지 않습니다.
로컬 확장다운로드한 확장 패키지와 설치 정보를 기기에 보관합니다. 설치와 활성화는 별도 단계입니다.
미디어 캐시이미지·영상·음성·PDF를 미리보기 위해 원본을 변경하지 않고 기기에 복사합니다. 작업공간마다 최대 512 MiB를 사용하고 닫힌 캐시부터 정리합니다.

프로필의 시작 명령, 스니펫이나 프로젝트 파일에 직접 입력한 비밀번호·토큰은 Keychain 항목으로 자동 분리되지 않습니다. 명령 기록의 비밀 값 필터도 모든 비밀을 판별하지 못하므로 중요한 값은 입력하거나 기록하기 전에 확인해 주세요.

재연결 복구용 미저장 편집 내용은 메모리에 유지하며 디스크에 자동 저장하지 않습니다. 앱 프로세스가 종료되면 해당 내용을 복구하지 못할 수 있습니다.

4. Open VSX와 확장 기능

확장을 검색하면 검색어를 Open VSX에 전달합니다. 설치 과정에서는 확장 ID, 버전과 대상 플랫폼을 요청하며 Open VSX 또는 허용된 패키지 CDN에서 다운로드합니다. 로컬 확장은 기기에서, 서버 확장은 연결한 SSH 서버에서 패키지를 내려받습니다.

이 요청의 수신자는 출발지 IP 주소와 요청 정보를 볼 수 있습니다. 기기에 요청 기록을 영구 저장하지 않는 설정이 외부 서비스의 로그 보관까지 막지는 않습니다.

기기에서 실행하는 확장

활성화한 로컬 확장은 선택한 프로젝트를 읽고 열린 문서를 편집·저장할 수 있습니다. 현재 로컬 확장 실행 환경과 미리보기의 콘텐츠 보안 정책 및 네이티브 브리지는 외부 네트워크 요청을 제한하며 비영속형 웹 데이터 저장소를 사용합니다. 이를 모든 제3자 코드의 동작을 보장하는 완전한 보안 경계로 간주하지 않습니다.

서버에서 실행하는 확장

서버 확장은 SSH 사용자 권한으로 실행되며 서버 파일·프로세스·네트워크에 접근할 수 있습니다. 실행 환경은 확장에 세션 식별자와 서버 저장 경로를 해시한 실행 환경 식별자도 제공합니다. 필요한 서버 실행 프로그램을 받기 위해 Node.js 배포 서비스에 요청할 수 있습니다.

확장이 AI·로그인 등 외부 서비스에 연결하면 코드, 파일 내용, 채팅과 계정 관련 정보를 그 서비스에 전달할 수 있습니다. 서버 확장의 파일·상태·인증 정보는 앱의 기기 Keychain과 별개로 관리됩니다.

외부 서비스의 보관 기간·이용 목적·사용자 연결·추적 여부는 각 제공자의 공식 정책과 해당 기능의 설정을 확인해야 합니다. 앱에 자체 자동 분석 업로드가 없다는 설명이 확장 자체의 수집·전송까지 차단한다는 뜻은 아닙니다.

  • Open VSX와 관련 패키지 제공자: Eclipse Foundation 개인정보처리방침
  • Node.js 관련 제공자: OpenJS Foundation 개인정보처리방침
  • 확장·AI·로그인 서비스와 Files 제공자: 사용자가 선택한 제공자의 공식 개인정보처리방침

이 방침의 기기 저장·삭제 설명은 외부 제공자의 서버 기록이나 계정 정보에 대신 적용되지 않습니다. 외부 서비스의 이용과 정보 삭제는 해당 제공자의 정책과 절차를 따릅니다.

5. 보관과 삭제

  • 서버 프로필: 삭제하면 기기의 해당 프로필과 앱이 관리하는 해당 SSH 자격 정보를 함께 삭제합니다. 앱 제거만으로 Keychain 항목 삭제를 보장하지 않으므로 앱을 제거하기 전에 프로필을 먼저 삭제해 주세요.
  • 프로젝트와 외부 폴더: 로컬 프로젝트는 Files에서 관리할 수 있습니다. 외부 폴더는 작업공간을 닫으면 앱의 활성 접근이 해제되지만 폴더 등록 정보는 남습니다. 이 동작이 제공자에 저장된 파일을 삭제하지는 않습니다.
  • 명령 기록과 스니펫: 터미널 도구에서 삭제할 수 있습니다. 명령 기록을 끄는 것만으로 기존 기록이 지워지지는 않습니다.
  • 미디어 캐시: 탭을 닫아도 다시 열기 위한 캐시가 남을 수 있습니다. 작업공간을 닫거나 캐시 비우기를 선택하면 소유한 캐시를 삭제합니다. 캐시는 기기 파일 보호를 적용하고 백업에서 제외합니다. 강제 종료 후 남은 캐시는 OS가 정리할 수 있으며 즉시 삭제를 보장하지 않습니다.
  • 확장: 비활성화해도 설치 패키지는 남습니다. 서버 확장의 설치 파일·상태와 외부 서비스의 기록은 해당 서버·서비스에서 별도로 관리해야 합니다.

프로필 삭제나 앱 제거가 SSH 서버의 원본 파일, Files 제공자의 클라우드 파일 또는 외부 서비스의 계정·대화 기록까지 삭제하지는 않습니다. 일반 프로젝트·설정 파일은 미디어 캐시와 달리 모두 백업 제외로 설정된 것은 아니며, OS 백업과 Files 동기화는 사용자 설정 및 제공자 정책에 영향을 받습니다.

6. 광고, 진단과 사용자 선택 공유

현재 앱에는 자체 광고 네트워크, 광고 추적, 사용 분석을 위한 자동 업로드 기능이 없습니다. 이 설명은 사용자가 연결한 서버·Files 제공자·확장·AI 서비스 전체의 데이터 관행을 뜻하지 않습니다.

네트워크 진단은 사용자가 선택한 연결 대상을 검사합니다. 지원용 버전 정보 복사는 앱 버전과 iOS·iPadOS 버전만 포함하며, 서버 프로필·파일 경로·명령 기록을 자동 첨부하지 않습니다.

사용자가 파일·터미널 출력·화면·진단 정보를 직접 공유하면 선택한 수신자와 앱으로 내용이 전달됩니다. 공유하기 전에 비밀번호, 토큰, 개인 정보와 내부 서버 주소가 포함되어 있는지 확인해 주세요.
