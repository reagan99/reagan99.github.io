01 / GET STARTED

처음 시작하기

서버 없이도 코드를 편집할 수 있나요?

홈 화면에서 새 로컬 프로젝트를 선택하면 기기에 파일을 만들고 편집·저장할 수 있습니다. 기존 폴더는 Files 폴더 열기로 선택하세요. Files에서 연 폴더는 사본이 아니라 원본을 편집하므로, 중요한 파일은 미리 백업해 주세요.

SSH 서버는 어떻게 연결하나요?

서버 프로필에 호스트, 포트, 사용자 이름과 인증 방법을 입력하고 연결하세요. 처음 연결할 때 표시되는 호스트 키 지문을 서버 관리자에게 별도로 확인한 뒤 승인하세요. 호스트 키가 바뀌었다면 변경 사유를 먼저 확인해 주세요.

02 / CONNECTION

SSH와 VPN 연결

연결 중 화면에서 멈추거나 접속하지 못해요.

서버 주소와 SSH 포트가 맞는지, 서버가 동작하는지 확인하세요. 회사 내부망이라면 이 iPhone 또는 iPad에서 VPN을 연결해야 합니다. Mac의 VPN 연결과 실제 기기의 VPN 연결은 별개입니다.

앱의 네트워크 진단에서 대상 서버의 경로와 TCP 연결을 확인할 수 있습니다. 회사의 앱별 VPN·접근 정책은 관리자에게 확인해 주세요. 기기 설정에서 앱의 로컬 네트워크와 셀룰러 사용 권한도 확인하세요.

홈 화면에 다녀오면 다시 연결되기도 하나요?

앱은 화면 전환만으로 정상 SSH 연결을 끊지 않습니다. 다만 iOS의 앱 정지, VPN 상태, 서버 설정에 따라 연결이 실제로 종료될 수 있습니다. 복귀 후 연결을 확인하고 필요한 경우 복구합니다.

계속 실행해야 하는 서버 작업은 서버의 tmux 같은 세션 도구를 사용하면 기기 연결과 별개로 작업을 이어갈 수 있습니다. 닫기 전에는 편집한 파일을 저장해 주세요.

비밀번호와 개인키는 어디에 저장되나요?

앱이 관리하는 SSH 비밀번호·개인키·암호구는 이 기기의 Keychain에 저장되며 다른 기기로 동기화하지 않습니다. 서버 프로필을 삭제하면 연결된 앱 관리 자격 정보도 삭제합니다. 기기 저장 정보 자세히 보기

03 / FILES & EDITING

편집과 파일 미리보기

파일을 저장할 때 충돌 안내가 나와요.

앱이 파일을 연 뒤 다른 프로그램이 원본을 바꾸었을 수 있습니다. 변경 내용을 확인하고 보관할 버전을 선택해 주세요. 앱이 종료되면 미저장 편집 내용이 사라질 수 있으니 중요한 변경은 자주 저장하세요.

이미지·영상은 다운로드되나요, 캐시인가요?

미리보기는 원본을 유지하고 기기의 보호된 캐시로 준비해 편집기 영역의 탭에서 엽니다. Files나 Downloads에 별도 파일을 저장하는 동작과는 다릅니다. 원격 파일은 전체 전송이 완료된 뒤 열리므로 큰 영상은 준비 시간이 걸릴 수 있습니다.

작업공간별 캐시는 최대 512 MiB이며 닫힌 탭의 오래된 항목부터 정리합니다. 원본을 다시 읽으려면 뷰어의 새로고침을, 캐시를 지우려면 작업공간의 미디어 탭 닫고 캐시 비우기를 사용하세요. 지원 형식 안에서도 코덱과 기기에 따라 재생 가능 여부가 달라집니다.

키보드를 내려도 특수 키를 쓸 수 있나요?

터미널 보조 바의 키보드 버튼으로 화면 키보드를 내릴 수 있습니다. 보조 바는 남아 있어 Esc, Ctrl·Alt, 방향키와 펼친 특수 키패드를 계속 사용할 수 있습니다.

04 / EXTENSIONS

확장 기능

확장은 어떻게 사용하나요?

작업공간의 확장에서 Open VSX 패키지를 검색해 설치하세요. 설치한 확장을 열고 필요한 경우 제3자 코드 신뢰 안내를 확인해 활성화합니다. 파일 뷰어 확장은 해당 파일을 탐색기에서 열 때 사용할 수 있습니다.

확장은 게시자가 만든 제3자 코드입니다. 로컬 확장은 선택한 프로젝트를 읽고 열린 문서를 편집·저장할 수 있으며, 서버 확장은 SSH 사용자 권한으로 실행됩니다. 신뢰할 수 있는 게시자의 확장만 사용하세요.

같은 확장이 로컬과 SSH에서 다르게 동작하나요?

확장마다 필요한 API와 실행 프로그램이 다릅니다. 로컬 작업공간은 기기에서 지원하는 명령과 읽기 전용 뷰어를 실행하며, SSH 작업공간은 연결한 서버의 실행 환경을 사용합니다. Node.js나 별도 실행 파일을 요구하는 확장은 서버 환경이 필요할 수 있습니다.

AI 서비스를 사용하는 확장에는 해당 서비스의 계정과 이용 조건이 적용됩니다. 코드·채팅·파일이 서비스에 전달될 수 있으니 각 제공자의 개인정보처리방침을 확인하세요.

확장이나 PLY 뷰어를 열지 못했어요.

확장 이름·버전, 로컬/SSH 작업공간 구분과 오류 문구를 확인해 주세요. 파일 뷰어는 파일 형식과 확장이 지원하는 인코딩·구성에 영향을 받습니다. 재현에 필요한 최소 정보만 지원 메일로 보내 주세요. 원본 파일 전체나 서버 자격 정보를 보내실 필요는 없습니다.
